## 2. Tooling Decisions & Best Practices

- **Obsidian / Markdown Notes:** Obsidian does not generate notes automatically; it reflects the folder on disk. Claude Code can read/write `.md` notes directly (e.g., this file) to maintain cheap context between sessions (~200 tokens) rather than re-reading large history files.
- **Graphify / Complex Graph Tooling:** Skip for small/medium projects. Default AST mode is free, but deep mode burns tokens. Not worth the maintenance overhead for small codebases.
- **Multi-Agent Swarms:** Avoid building an orchestrator/framework from scratch as a beginner. Start with **Explore $\rightarrow$ Plan $\rightarrow$ Implement** loops with a single agent or custom subcommands (`.claude/commands/`).
